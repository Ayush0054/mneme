# Bundled typefaces

Original, unmodified font files from the Google Fonts repository:

- Instrument Serif Regular and Italic: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- DM Sans variable (optical size and weight): https://github.com/google/fonts/tree/main/ofl/dmsans

Retrieved September 19, 2026. DM Sans's upstream filename is
`DMSans[opsz,wght].ttf`; the local filename is `DMSans-Variable.ttf`.
The file contents and font's internal name are unchanged.
Its registered PostScript name is `DMSans-9ptRegular`, as declared in Google's
`ofl/dmsans/METADATA.pb`.

Both fonts ship under the SIL Open Font License. Their original notices and
license texts are included in `InstrumentSerif-OFL.txt` and `DMSans-OFL.txt`.
The app registers these fonts for its own process; it does not install fonts
system-wide or download them at runtime.
